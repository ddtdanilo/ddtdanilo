# Security Policy

## Supported content

Only the current `main` branch is maintained. This repository contains profile
content and validation automation; it does not provide a deployed application
or runtime service.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the repository's Security
tab. Please do not open a public issue for credential exposure, workflow
injection, personal-data disclosure, or another security-sensitive finding.

Include the affected path, impact, reproduction steps, and a suggested
remediation when possible. You can expect an initial response within seven
days.

Do not include live credentials or unnecessary personal information in a
report. Good-faith reports will be handled respectfully.
